# AUTO KERUBIM APEX-SETTINGS
This simple script automatically downloads and installs your Apex Legends configuration files to the correct folders.

What it does

Detects your Windows username
Creates the Apex Legends settings folder in:
C:\Users\<YourUsername>\Saved Games\Respawn\Apex
Downloads your saved settings files to:
Local settings (3 files)
Profile settings (2 files)
Also installs the Steam autoexec config file
How to use

Run the script
It automatically downloads and places your files
Launch Apex Legends to use your settings
No manual file copying needed!


## STEP 1
- download the exe on github
- exec ( that gonna auto-download all my settings and place it on your pc )

## STEP 2
- put this on your apex lunch option 
-dev -high +building_cubemaps 1 +mat_letterbox_aspect_goal 0 +mat_letterbox_aspect_threshold 0 +cl_showpos 1 +cl_is_softened_locale 1 +exec autoexec.cfg
